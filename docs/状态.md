## 1. 一句话

DeepSeek Harness 多租户插件：**内嵌认证反代网关**（登录/RBAC/配额/会话归属强制）+ 自建 `/mt`
管理通道 + `node:sqlite` 数据层，DSH 零改源码；提供平台管理员/租户管理员/审计员/使用者四角色，
邮箱密码 / LDAP / SSO-OIDC 三种登录，token 用量统计与三级配额，全程审计。

## 2. 架构

```
浏览器 ──► 网关(:3090) [登录/RBAC/配额/归属强制 + HTTP/WS 代理] ──► 127.0.0.1:<DSH端口>
                                                                        │
                          浏览器也直连 DSH(:3080)（开发者模式；/api/auth/* 与 /mt 由插件进程内提供）
```

- **网关**（`lib/host/gateway.js`）：认证反代；非公开路径全量登录强制；POST /api 缓冲信封做
  会话归属（`session.create` 强制前缀 `u-<uid>-t-<tid>-s-*`、会话作用域校验越权 403+审计）；
  `session.prompt/subagent.prompt` 前置配额检查；统一安全响应头；WS upgrade 校验 Cookie
- **/mt 通道**（`mt-channel.js`）：挂 DSH webserver 的 `/api/auth` 之外的 RPC 面（RPC 信封协议），
  管理/统计/审计/配额 API，端点级 RBAC
- **认证**（`auth-service.js` + `auth/local` via crypto.js、`auth/ldap.js`、`auth/oidc.js`）：
  本地 scrypt + 会话令牌 SHA-256 摘要；LDAP 目录绑定验证+自动建号；OIDC Authorization Code+PKCE
- **计量**（`metering.js` + `quota.js`）：`tokenUsage` 投影四桶差分记账 → usage_records + 配额累计；
  平台/租户/用户 × 日/月/累计，周期窗口滚动
- **RBAC**（`rbac.js`）：system > admin > auditor > user；租户隔离；用户管理边界
- **数据**（`db.js`）：`node:sqlite`（WAL、`user_version` 迁移 v2）；
  tenants/users/auth_sessions/audit_logs/login_attempts/usage_records/session_meter/quotas/quota_usage

## 8. 安全边界（明示）

- 逻辑隔离（会话/权限/配额/数据/审计），**无进程级隔离**（模型与工具同 UID）
- 远程用户无法使用 DSH 特权方法（settings/credentials/host.*，loopback-only）
- 直连 DSH 端口 = 开发者模式（无 /api 强制）；生产只暴露网关端口
- 防爆破：账号+IP 窗口计数，连续失败自动锁定；登录失败全量审计
